Punctuation

\key Punctuation_and_Special_Codes

Generally, leave off all punctuation at the end of bookkeeping fields and basic data fields (\hm, \sn, \ge, \lf, etc.). The only places where you need to include punctuation is in and at the end of free-form (discussion type) fields (\ue, \ee, \nt, etc.). In all other data fields, final punctuation is added by MDF automatically. For a list of free-form fields, see:

Free-form_Fields

Toolbox allows you to hard code the following special characters directly into you lexical database (this works for both the RTF and the MDF exporting process):

   |{tab}          Inserts a Tab character
   |{endash}       Inserts an En-dash character
   |{emdash}       Inserts an Em-dash character
   |{~}            Inserts a non-breaking space
   |{-}            Inserts an optional hyphen
   |{_}            Inserts a non-breaking hyphen
