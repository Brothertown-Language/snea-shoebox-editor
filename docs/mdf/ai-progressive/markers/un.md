# \un usage (national)

*\key* \un

The national language equivalent to the \ue field. This field should cover information such as
common usage, or restrictions in usage. For more information, see:

\cf \ue usage (English)

MDF initially adds the label "NatUsage: " to this field. This is later changed to whatever
national language label is specified for this field in the national audience CC table. For more
information on this, see:

\cf Printed_Field_Labels

Identical English and regional language fields are:

\cf \ue and \ur

Closely related fields are:

\cf \dn, \en, and \on 

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
