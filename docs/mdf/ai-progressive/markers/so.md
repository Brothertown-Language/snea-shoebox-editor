# \so source of data

*\key* \so

This is a place to indicate the name and village of the informant who gave you the data in the
current entry. There is no standard way such information should be encoded.

If selected for output, MDF adds the label "Source: " to this field and brackets it with "[ ]".

*\nt* This field does not normally print.

*\typ* <Optional>

## Data handling

Carries the source of the data for provenance tracking.
