# \pdn paradigm form (national gloss)

*\key* \pdn

This is used for glossing the vernacular paradigm form in the national language. For the related
glossing fields, see:

\cf \pde paradigm form-English gloss

\cf \pdr paradigm form-regional gloss

For a more detailed explanation of this set of fields, see:

\cf \pdl paradigm label

\cf \pdv paradigm vernacular form

For more information on the paradigm fields, see:

\cf \pd paradigm set
