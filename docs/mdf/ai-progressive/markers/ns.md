# \ns notes on sociolinguistics

*\key* \ns

This is used for encoding sociolinguistic notes. Dialect information (i.e. which villages use this
lexeme form, etc.) should be explained in the following fields:

\cf \ue, \un, \ur (Usage)

\cf \ee, \en, \er (Encyclopedic) 

\cf \oe, \on, \or (Only --restrictions)

If selected for output, MDF adds the label "Socio: " to this field and brackets it with "[ ]".

For generic notes, see: 

\cf \nt

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
