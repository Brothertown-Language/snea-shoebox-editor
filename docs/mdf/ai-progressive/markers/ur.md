# \ur usage (regional)

*\key* \ur

The regional language equivalent to the \ue field. This field should cover information such as
common usage, or restrictions in usage. For more information, see:

\cf \ue usage (English)

MDF adds the brackets "[ ]" around this field. If included in the output, it is treated as part of
the national field.

Identical English and national language fields are:

\cf \ue and \un

Closely related fields are:

\cf \dr, \er, and \or 

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
