# \lr lexical function (regional gloss)

*\key* \lr

This is for giving the regional gloss of the vernacular lexeme referenced by the lexical function.

For more information, see:

\cf \lf lexical function label

\cf \lv vernacular lexeme referenced by the lexical function

Related fields are:

\cf \le and \ln

For generic cross-referencing, see:

\cf \cf confer/cross-reference

*\typ* <Optional>

Carries the regional-language gloss of the referenced lexeme.
