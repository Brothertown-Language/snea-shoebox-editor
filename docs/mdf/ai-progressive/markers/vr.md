# \vr variant comment (regional)

*\key* \vr

This is bundled with the \va field and is where regional language comments can be given for
the variant form. For more information, see:

\cf \va variant forms

If this field is included in the output, MDF adds parentheses "( )" around it and it is treated as
part of the national field.

The related comment fields are:

\cf \ve and \vn

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
