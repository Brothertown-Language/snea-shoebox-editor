# \cn cross-reference (national gloss)

*\key* \cn

This gives the national language gloss for the vernacular lexeme referenced by the preceding
 \cf field. 

For more information, see:

\cf \cf confer/cross-reference

Identical English and regional language gloss fields are:

\cf \ce and \cr
