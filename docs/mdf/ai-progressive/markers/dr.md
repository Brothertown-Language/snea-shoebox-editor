# \dr definition (regional)

*\key* \dr

Often early in the project the definitions we receive are actually in the regional language, not
the national language; such definitions could be stored here. 

If this field is included in the output, MDF adds a label and brackets "[ ]" around it and it is
treated as part of the national field.

For more information, see "Hint" under:

\cf \de definition (English)

See also:

\cf \gr gloss (regional)

For the related definition fields, see:

\cf \dv, \de, and \dn

Closely related regional language fields are:

\cf \ur, \or, and \er
