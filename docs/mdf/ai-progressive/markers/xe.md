# \xe translation of example (English)

*\key* \xe

This provides the English translation of the example sentence given in the \xv field.

For more information about example sentences, see: 

\cf \xv example sentence (vernacular)

\cf \rf reference to notebooks, texts, etc.

Related fields are:

\cf \xn and \xr

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
