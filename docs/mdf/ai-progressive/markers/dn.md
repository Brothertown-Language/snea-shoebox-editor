# \dn definition (national)

*\key* \dn

This field is used to fully express the semantic domains of each sense of a lexeme in the
national language. 

For more information, see "Hint" under:

\cf \de definition English

See also:

\cf \gn gloss national

For the related definition fields, see:

\cf \dv, \de, and \dr

Closely related national language fields are:

\cf \un, \on, and \en
