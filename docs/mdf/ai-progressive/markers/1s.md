# Old verb paradigm markers

*\key* \1s \1p \1e \1i \1d \2s \2p \2d \3s \3p \3d \4s \4p \4d

These fields were for various possible verb paradigm forms. For example

*\ftx*

```text
 \1s yoban
```

These markers are no longer used. See the topic
