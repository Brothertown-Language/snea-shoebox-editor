# \pde paradigm form (English gloss)

*\key* \pde

This is used for glossing the vernacular paradigm form in English, e.g.:

*\ftx*

```text
 \pdl Pl
 \pdv asure
 \pde dogs
 \pdn anjing-anjing
```

This will typically print as:

*\fxv*

```text
 Pl: asure 'dogs' 'anjing-anjing'.
```

where the paradigm label is italic, the vernacular form is in vernacular font, and the two
glosses are in their appropriate language fonts.

For a more detailed explanation of this set of fields, see:

\cf \pdl paradigm label

\cf \pdv paradigm vernacular form

For the related glossing fields, see:

\cf \pdn paradigm form-national gloss

\cf \pdr paradigm form-regional gloss

For more information on the paradigm fields, see:

\cf \pd paradigm set
