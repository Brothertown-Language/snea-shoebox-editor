# \nd notes on discourse

*\key* \nd

This is a place for your notes on discourse/text analysis, should you wish to keep them
separate.

If selected for output, MDF adds the label "Disc: " to this field and brackets it with "[ ]".

For generic notes, see: 

\cf \nt

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
