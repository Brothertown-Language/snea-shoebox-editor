# \ec etymology-comment

*\key* \ec

Any comments the researcher needs to add concerning the etymology of the lexeme can be
given here.

For more information, see:

\cf \et 

*\nt* This field does not normally print.

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
