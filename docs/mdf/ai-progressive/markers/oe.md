# \oe only [restrictions] (English)

*\key* \oe

This is for encoding any semantic and/or grammatical restrictions pertinent to the lexeme. 

In Buru, the lexeme 'anafina' is glossed as 'female'. But this needs to be restricted to only
'human' references, which could be encoded as:

*\ftx*

```text
 \oe Human
```

and would print as:

*\fxv*

```text
 Restrict: Human.
```

Since this is a free-form field, you can be as verbose as needed, but in many cases, such as
this one, a simple code may suffice.

Closely related English fields are:

\cf \de, \ue, and \ee 

Identical national and regional language fields are:

\cf \on and \or

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
