# \ln lexical function (national gloss)

*\key* \ln

This is for giving the national gloss of the vernacular lexeme referenced by the lexical function.

For more information, see:

\cf \lf lexical function label

\cf \lv vernacular lexeme referenced by the lexical function

Related fields are:

\cf \le and \lr

For generic cross-referencing, see:

\cf \cf confer/cross-reference

*\typ* <Optional>

## Semantics

Carries the national-language gloss of the referenced lexeme.

Listed under [Semantics](../concerns/semantics.md).
