# \pl plural form

*\key* \pl

This is a special field used to give the plural form of the lexeme, e.g. in Selaru,
the plural form of the lexical entry 'asw' ('dog') is entered as:

*\ftx*

```text
 \pl asure
```

MDF adds a "Pl: " label to this form. The data is formatted as vernacular text.

For more flexible labeling and to allow for glossing, MDF provides the following
set of paradigm fields:

\cf \pdl paradigm label

\cf \pdv paradigm vernacular form

\cf \pde paradigm form-English gloss

\cf \pdn paradigm form-national gloss

\cf \pdr paradigm form-regional gloss

For related fields, see:

\cf \sg singular form

\cf \pd paradigm set
