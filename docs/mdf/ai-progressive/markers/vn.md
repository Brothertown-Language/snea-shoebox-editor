# \vn variant comment (national)

*\key* \vn

This is bundled with the \va field and is where national language comments can be given for
the variant form. For more information, see:

\cf \va variant forms

MDF adds parentheses "( )" around this field.

The related comment fields are:

\cf \ve and \vr

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.

*\typ* <Optional>
