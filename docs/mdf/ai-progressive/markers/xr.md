# \xr translation of example (regional)

*\key* \xr

This provides the regional translation of the example sentence given in the \xv field.

MDF adds the brackets "[ ]" around this field. If included in the output, it is treated as part of
the national field.

For more information about example sentences, see: 

\cf \xv example sentence (vernacular)

\cf \rf reference to notebooks, texts, etc.

Related fields are:

\cf \xe and \xn

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
