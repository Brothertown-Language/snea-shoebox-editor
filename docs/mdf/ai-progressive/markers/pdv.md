# \pdv paradigm vernacular form

*\key* \pdv

This field is used to give the vernacular paradigm form specified by the label in the \pdl field,
e.g.:

*\ftx*

```text
 \pdl 1s
 \pdv koban 
```

where "koban" is the first-singular verb form of the verb root "-oban". MDF will format the '1s'
label as italic, and the contents of the \pdv field as vernacular text. 

For a more detailed explanation, see:

\cf \pdl paradigm label

For the related glossing fields, see:

\cf \pde paradigm form-English gloss

\cf \pdn paradigm form-national gloss

\cf \pdr paradigm form-regional gloss

For more information on the paradigm fields, see:

\cf \pd paradigm set
