# \pdr paradigm form (regional gloss)

*\key* \pdr

This is used for glossing the vernacular paradigm form in the regional language. For the related
glossing fields, see:

\cf \pde paradigm form-English gloss

\cf \pdn paradigm form-national gloss

For a more detailed explanation of this set of fields, see:

\cf \pdl paradigm label

\cf \pdv paradigm vernacular form

For more information on the paradigm fields, see:

\cf \pd paradigm set
