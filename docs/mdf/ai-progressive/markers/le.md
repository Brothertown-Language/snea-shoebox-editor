# \le lexical function (English gloss)

*\key* \le

This is for giving the English gloss of the vernacular lexeme referenced by the lexical function.

For more information, see:

\cf \lf lexical function label

\cf \lv vernacular lexeme referenced by the lexical function

Related fields are:

\cf \ln and \lr

For generic cross-referencing, see:

\cf \cf confer/cross-reference
