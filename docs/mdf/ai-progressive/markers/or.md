# \or only [restrictions] (regional)

*\key* \or

The regional language equivalent to the \oe field. This field is for clarifying semantic and
grammatical restrictions pertinent to the lexeme. 

If included in the output, MDF adds brackets "[ ]" around this field, and it is treated as part of
the national field. 

For more information, see:

\cf \oe

Closely related regional fields are:

\cf \dr, \ur, and \er 

*\nt* This is a "free-form" field. Punctuation and capitalization should be used as needed.
