# \sg singular form

*\key* \sg

This is a special field used to give the singular form of the lexeme, e.g. in Selaru,
the singular form of the lexical entry 'asw' ('dog') is entered as:

*\ftx*

```text
 \sg askwe
```

MDF adds a "Sg: " label to this form. The data is formatted as vernacular text.

For more flexible labeling and to allow for glossing, MDF provides the following
set of paradigm fields:

\cf \pdl paradigm label

\cf \pdv paradigm vernacular form

\cf \pde paradigm form-English gloss

\cf \pdn paradigm form-national gloss

\cf \pdr paradigm form-regional gloss

For related fields, see:

\cf \pl plural form

\cf \pd paradigm set
