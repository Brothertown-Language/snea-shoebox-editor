# \mr morphemic representation

*\key* \mr

This can be used to show the underlying morphemic structure for complex lexemes. MDF
gives this field the label 'Morph:'

In Buru, the lexeme 'agat' ('grain') is a complex morpheme. Its internal structure should be
encoded as:

*\ftx*

```text
 \mr aga-t
```

This will typically print as:

*\fxv*

```text
 Morph: aga-t.
```

*\typ* <Optional>

## Semantics

Carries the morphemic representation analyzing the form's structure.
