# \ev encyclopedic information (vernacular)

*\key* \ev

This field contains the vernacular description of any pertinent encyclopedic information related
to the lexeme or headword, subentry, or sense. This is intended for use in a monolingual
dictionary, but can be used in diglot and triglot dictionaries as well. 

For more information, see:

\cf \ee

Related fields are:

\cf \gv, \dv, \ov, \uv
